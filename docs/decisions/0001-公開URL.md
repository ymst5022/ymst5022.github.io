# 0001 公開URL

状態: 採用（2026-10-29）
決めたこと: 公開URLは `https://ymst5022.github.io/`（GitHub Pages のユーザーサイト。リポジトリは `ymst5022/ymst5022.github.io`）。QRにはこのURLの文字列だけを入れる。
理由: 紙の名刺にQRを印刷したあともURLを変えないため。いちばん短く、無料で、リポジトリ名の変更にも左右されない（設計書 `docs/design/2026-10-29-devcard.md` の P3・P7、D1・D2）。
却下した案: プロジェクトサイト `https://ymst5022.github.io/devcard/`（リポジトリ名を変えるとURLが変わり、印刷したQRが使えなくなる）。最初から独自ドメイン（費用がかかり、更新を忘れるとQRが使えなくなる）。
見直す条件: 独自ドメインを取るとき（github.io のURLは自動で転送される）、またはGitHubのユーザー名を変えるとき。
