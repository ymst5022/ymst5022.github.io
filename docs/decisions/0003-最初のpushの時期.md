# 0003 最初のpushの時期

状態: 採用（2026-10-29）
決めたこと: 公開リポジトリへの最初の push は、`profile.ts` の下書き（`TODO`）がすべて確定してから行う。リポジトリの作成・push・Pages の公開設定は毎回ユーザーに確認してから行う。push の前に、コミットの中身と作者名・作者メールに載せたくない情報が無いことを確かめる。
理由: push した中身は誰でも見られ、履歴にも残って取り消しにくいため（設計書の P14、D15・D20、決定 0002）。
却下した案: 早めに push して自動公開の仕組みを先に確かめる（下書きが公開リポジトリで見えてしまう）。
見直す条件: リポジトリを非公開にするとき。
