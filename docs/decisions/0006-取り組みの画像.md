# 0006 取り組みの画像

状態: 採用（2026-10-30）
決めたこと: 非公開のプロジェクトも、「取り組み」の欄に画面の画像と説明で載せてよい。ただしリポジトリへのリンクは付けず、画像には鍵・合言葉・メール・アカウント名・自分の感想・お金の情報・他人の投稿を写さない。画像は1枚 200KB 以下（`npm run check:publish` で検査）で、立ち絵などは作者を添える。「いま取り組んでいること」の箇条書きは使わない。
理由: 作っているものを、文章より伝わりやすい画面で紹介したいため（ユーザーの依頼「画面をキャプチャーして、こんなことをやっていますという紹介ができたらいい」）。設計の前提 P5「未公開のプロジェクトは載せない」を見直した。
却下した案: 未公開のものは載せない（最初の P5。紹介したい内容が伝わらない）。箇条書きとカードの両方を残す（同じ内容が2回出る）。見出しを「制作物」のままにする（開発中のものを紹介するため「取り組み」にした）。
見直す条件: リポジトリを公開したとき（リンクを付ける）、または画像から載せたくない情報が漏れたとき。
