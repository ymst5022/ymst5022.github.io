# 0002 載せる個人情報

状態: 採用（2026-10-29）
決めたこと: ページと連絡先ファイル（vCard）にはハンドルネームだけを載せ、本名・メールアドレス・住所・電話番号は載せない。コミットの作者メールには GitHub の非公開用アドレス（noreply）を使う。
理由: 公開ページと公開リポジトリに載せた情報は取り消しにくく、迷惑メールを防ぎたいため。連絡は GitHub・X・Discord で受ける（設計書の P5・P9・P11、D6・D17・D20）。
却下した案: メールアドレスを載せる（迷惑メールが届く恐れ）。本名を載せる、本名とハンドルネームを併記する（本名がネットに残る）。
見直す条件: 名刺用に公開してよいメールアドレスを用意したとき（`profile.ts` の `links.email` に値を入れるだけで表示と vCard に出る）。
