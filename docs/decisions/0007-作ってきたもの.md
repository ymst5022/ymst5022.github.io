# 0007 作ってきたもの

状態: 採用（2026-10-31）
決めたこと: 「取り組み」の下に「作ってきたもの」の欄を置き、画像もリンクも付けず、名前・説明・技術だけの箇条書きにする。外のサービスの規約やルールに触れるおそれがあるものは載せない。
理由: ユーザーの依頼「イメージはいらないので箇条書きでどんなシステムを作ってきたかを記載してください」のため。名刺のページは誰でも見られるので、外から見て問題になりうるものは避ける。載せるものはユーザーが候補から選んだ（決定 0006 と同じく、非公開のものにはリンクを付けない）。
却下した案: 画像付きのカードにする（依頼で画像は不要とされた）。候補をすべて載せる（規約やルールに触れるおそれがあるものが含まれていた）。このデジタル名刺そのものを載せる（ユーザーが選ばなかった）。
見直す条件: 載せたいもののリポジトリを公開したとき（リンクを付ける）、または規約に触れないと確かめられたとき。
