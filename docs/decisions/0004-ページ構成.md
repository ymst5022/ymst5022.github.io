# 0004 ページ構成

状態: 採用（2026-10-29）
決めたこと: ページは1枚で、ルーター（画面切り替えの仕組み）は入れない。上から プロフィール → つながる → 制作物 → 連絡先保存・URLコピー と並べ、QRは右上の「QRを表示」ボタンで全画面（`<dialog>`）に出す。
理由: 読み取った相手がまずプロフィールを見られ、見せる側もボタン1回で大きなQRを出せ、仕組みも少ないため（設計書の P1・P2・P3、方針A、D4・D7）。
却下した案: ページ下部に共有欄を常に出す（見せるたびにスクロールが要り、QRが小さい）。見せる専用画面 `/#share` を分ける（切り替えの仕組みが増える）。
見直す条件: イベントで使ってみて、QRを出すまでの手間が問題になったとき。
