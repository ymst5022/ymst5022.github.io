# 0005 見た目

状態: 採用（2026-10-30）
決めたこと: 見た目は明るい色を基調にし、アクセント色の淡い光の背景と半透明のカード（案A）にする。動きは4種類だけ（表示時に浮き上がる・背景の光が揺れる・触ると浮く・QR と通知がふわっと出る）入れ、動きを減らす設定（prefers-reduced-motion）の端末では止める。文字と背景のコントラスト比は 4.5 以上を保ち、QR は白地に黒のままにする。
理由: もっとモダンで明るい印象にしたいため（ユーザーの依頼「デザインをもう少しモダンな形にして、背景なども入れてください」「ダークグレーではなく明るい色を基調としたものにしてください」）。設計 D12・P13 を更新した。
却下した案: ダークグレー基調で動き無し（最初の設計。モダンさが足りない）。方眼の背景（案B）とカバー付きカード（案C）は、比較した上で案A が選ばれた。
見直す条件: 薄暗い会場でまぶしいと分かったとき、または動きでスマホが重くなったとき。
