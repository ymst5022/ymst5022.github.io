# 設計: デジタル名刺サイト（DevCard）

- 日付: 2026-10-29
- 状態: 承認済み（2026-10-29）
- 更新: 2026-10-30 見た目（P13・D12）を、ユーザーの依頼「明るい色を基調に、背景とアニメーションを入れる」に合わせて変更
- 更新: 2026-10-30 「制作物」の欄を「取り組み」にし、非公開の取り組みも画面の画像と説明で紹介できるようにした（P5・Work の型。決定 0006）。「取り組み中のこと」の箇条書きは空にした
- 更新: 2026-10-31 「取り組み」の下に「作ってきたもの」の欄を足した。ユーザーの依頼「イメージはいらないので箇条書きでどんなシステムを作ってきたかを記載」により、画像もリンクも付けず、名前・説明・技術だけを出す（BuiltWork の型）

## 前提シート（承認済み）

元の依頼:「IT系の勉強会、Discordコミュニティ、交流イベントなどで、自分を紹介するためのデジタル名刺サイトを作成する」「不必要な機能を追加せず、無料で長期利用できる、シンプルで保守しやすいデジタル名刺を構築する」（引継ぎ資料より）

| # | 種類 | 内容 |
|---|---|---|
| P1 | 目的 | 初めて会った相手に「どんな人か・何を作っているか・どこでつながれるか」を短時間で伝え、後でGitHubやSNSからつながってもらう |
| P2 | 使われ方 | 自分のスマホにQRを出し、相手がスマホで読み取る。DiscordなどにURLを貼る。将来は紙の名刺に同じQRを印刷する |

## 選んだ方針: A（1ページ＋「QRを表示」ボタンで全画面QR）

| 案 | 概要 | 良い点 | 悪い点 | 前提との相性 | 変えにくさ |
|---|---|---|---|---|---|
| **A（採用）** | 1ページ。プロフィール → つながり先 → 制作物 → 連絡先保存。右上の「QRを表示」で、白地の大きなQR・URLコピー・画像保存を出す | 相手はすぐプロフィールを読める。見せる側はボタン1回 | ボタンを1回押す手間 | P1・P2・P3-2 | 中 |
| B | 1ページの最下部に共有欄を常に表示 | 作りが最も単純 | スクロールが要る、QRが小さめ | P3-3 のみ | 低 |
| C | プロフィール画面と見せる専用画面（`/#share`）を切り替え | 会場で1タップ | 切り替えの仕組みが増える | P2 のみ | 中 |

採用理由: P1（相手がまずプロフィールを見る）と P2（すぐ大きなQRを出す）を満たし、仕組みが最も少ない（P3-3）。

## 型定義（D5）

```ts
// src/data/types.ts
export interface Profile {
  /** QRコードとURLコピーに使う公開URL。空文字なら「未設定」として案内を出す（D3） */
  siteUrl: string;
  /** 表示名（ハンドルネーム）。vCard の FN / N にも使う（P11） */
  handle: string;
  /** 文字アバターに出す文字。省略時は handle の1文字目（P12, D19） */
  avatarText?: string;
  /** アバター画像のパス（例: "/avatar.png"、public/ に置く）。設定すると文字アバターの代わりに出す（D19） */
  avatarImage?: string;
  /** 肩書き */
  title: string;
  /** 自己紹介。空行で段落を分ける */
  bio: string;
  /** 興味のある技術分野 */
  interests: string[];
  /** 今取り組んでいること */
  currentFocus: string[];
  links: Links;
  works: Work[];
  /** これまでに作ったもの。画像・リンクなしの箇条書き。2026-10-31 追加 */
  builtWorks: BuiltWork[];
}

export interface Links {
  /** 例: https://github.com/<ユーザー名> */
  github?: string;
  /** 例: https://x.com/<ユーザー名> */
  x?: string;
  /** 技術ブログのURL */
  blog?: string;
  discord?: DiscordLink;
  /** P9 により今は設定しない。必要になったら値を入れるだけで表示と vCard に出る */
  email?: string;
}

export interface DiscordLink {
  /** 表示とコピーに使うユーザー名 */
  username: string;
  /** 数字のユーザーID。あれば https://discord.com/users/<userId> へリンクする */
  userId?: string;
}

export interface Work {
  /** 名称 */
  name: string;
  /** 概要 */
  summary: string;
  /** 使用技術 */
  tech: string[];
  /** GitHub リポジトリの URL */
  repoUrl?: string;
  /** 公開している URL */
  url?: string;
  /** 名前の横に出す印（例: "開発中"）。2026-10-30 追加 */
  status?: string;
  /** 画面の画像。2026-10-30 追加（決定 0006） */
  image?: WorkImage;
}

/** 「作ってきたもの」の1項目。2026-10-31 追加 */
export type BuiltWork = Pick<Work, 'name' | 'summary' | 'tech'>;

export interface WorkImage {
  /** public/ に置いた画像のパス。1枚 200KB 以下（npm run check:publish で検査） */
  src: string;
  /** 画像の説明（読み上げ用） */
  alt: string;
  /** 画像の実際の幅と高さ */
  width: number;
  height: number;
  /** 画像の下に出すクレジット */
  credit?: string;
}
```
